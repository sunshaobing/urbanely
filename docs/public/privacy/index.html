一、适用范围

本应用面向上海申汰实业有限公司授权的现场服务人员，以及经客户授权在员工设备上完成签字的客户代表。未登录用户可以查看登录页、用户服务协议和本隐私政策；业务功能仅向授权账号开放。本应用不面向未成年人独立使用。

二、我们收集的信息及用途

  • 账号与身份信息：账号、姓名、角色、手机号、所属项目，用于登录、身份识别、任务分派和权限控制。
  • 客户与门店业务信息：客户名称、门店地址、联系人、联系电话、服务地址、勘测和封堵记录、材料、服务时间，用于现场服务、报告生成、客户交付和服务审计。
  • 精确位置：仅在用户主动点击“到达现场签到”或“现场签到”时，通过微信位置接口获取经纬度、定位精度和签到时间，用于核验是否到达任务指定的客户门店并生成现场考勤签到记录；不在后台持续定位、不追踪行动轨迹，也不用于附近门店推荐或广告。
  • 相机和相册信息：仅在用户主动拍摄或选择现场照片、结构风险照片、封堵前后照片和签字图片时获取，用于现场记录和报告生成。
  • 手写签字信息：员工或客户代表姓名、部门、签字图片和签字时间，用于客户确认、报告生成和归档。
  • 日志信息：登录时间、操作记录、网络请求、错误日志、IP和网络状态，用于账号安全、故障排查和服务审计。

三、设备权限说明

  • 位置权限（wx.getLocation）：用于员工到达客户门店后的现场考勤打卡。拒绝授权后无法完成签到，但不影响查看已分配任务和报告。
  • 相机权限：用于拍摄现场照片和签字图片。拒绝授权后无法拍照。
  • 相册权限：用于选择现场照片。拒绝授权后无法从相册上传。

本应用不收集微信昵称、微信头像、通讯录、麦克风、蓝牙或后台持续位置，不出售个人信息，不进行广告推送。仅在用户主动复制门店地址时写入系统剪贴板，不读取剪贴板内容。

四、信息存储与保护

数据存储在中华人民共和国境内的腾讯云服务器，通过HTTPS传输，按角色控制访问并记录操作日志。我们采取访问控制、操作日志和备份等措施保护信息安全。保存期限按照客户合同、公司档案制度及法律法规执行，超过期限后删除或匿名化处理。

五、信息共享

仅为服务交付向客户或其授权代表提供报告、照片和签字信息；公司内部仅向有权限的项目管理、审核、客服和系统运维人员提供必要信息；腾讯云提供服务器和存储服务，微信和 Apple 提供运行环境及平台服务；法律法规另有要求的除外。我们不会向无关第三方出售或提供个人信息。

六、你的权利

你可以通过项目主管或系统管理员查询、更正或删除个人信息，撤回位置、相机或相册授权，注销账号或停止使用。撤回授权后相关功能无法使用；依法或依合同必须保留的报告和审计记录，在保存期限届满后处理。

七、未成年人保护

本应用不面向未成年人独立使用。如涉及未成年人信息，应取得监护人同意；如有疑问，请联系运营者。

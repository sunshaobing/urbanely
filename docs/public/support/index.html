现场服务、账号与数据问题支持

账号与登录

本应用使用公司分配的账号，不开放自助注册。忘记密码或账号未启用，请联系项目主管或系统管理员重置和开通。

现场签到与定位

现场签到时请允许位置权限并开启手机定位服务。定位精度不足时请到开阔处重试；权限被拒绝后可在系统设置中重新开启。

照片、签字与报告

拍摄或选择照片需要相机/相册权限。签字完成后会生成白底签字图片并写入服务报告。报告问题请联系项目管理员核对。
